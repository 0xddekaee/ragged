# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-09-09

### Added

- Initial release of ragedd
- Configuration file at `configs/rag.yaml`
- Two example configurations: `minimal.yaml` and `production.yaml`
- Documentation for 10 common RAG problems:
  - Chunking (`docs/chunking.md`)
  - Retrieval (`docs/retrieval.md`)
  - Embeddings (`docs/embeddings.md`)
  - Query (`docs/query.md`)
  - Metadata (`docs/metadata.md`)
  - Context (`docs/context.md`)
  - Versioning (`docs/versioning.md`)
  - Hierarchy (`docs/hierarchy.md`)
  - Parsing (`docs/parsing.md`)
- GitHub Actions CI workflow
- Dependabot configuration
